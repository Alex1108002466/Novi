# MIU Guide (Novi) — задача для фронтенда

Бэкенд готов и отдаёт данные через REST API. Фронтенда пока нет вообще —
ни каркаса, ни выбранного стека. Всё, что ниже, нужно сделать с нуля,
включая выбор технологий.

## Что нужно сделать

Интерфейс цифрового помощника Novi по макету. Пошаговый мастер (не чат):
пользователь выбирает категорию → выбирает свою текущую точку → получает
маршрут на карте → подтверждает, что дошёл.

## Стек — на твой выбор

Никаких ограничений и готового каркаса нет. Делай на чём удобнее и быстрее
получится за время: чистый HTML/CSS/JS, React, Vue — что угодно.

## Как поднять бэкенд, чтобы дергать API при разработке

```bash
git clone <репозиторий>
cd <папка проекта>
python -m venv venv
venv\Scripts\activate            # Windows
pip install -r requirements.txt
copy .env.example .env
python -m app.seed_data
uvicorn app.main:app --reload
```

После этого:
- API: `http://localhost:8000`
- Живая интерактивная документация (можно тыкать запросы прямо в браузере): `http://localhost:8000/docs`
- CORS открыт полностью — фронт можно поднимать на любом порту, проблем с запросами из браузера не будет.

## Экраны, которые нужно сделать

По макету, в порядке пользовательского пути:

1. **Приветствие** — стартовый экран с кнопкой "Начать"
2. **Что ты хочешь найти?** — сетка категорий → `GET /categories`
3. **Список локаций выбранной категории** → `GET /locations?category={slug}`
4. **Где ты сейчас?** — выбор стартовой точки → `GET /locations?entry_points_only=true`
5. **Ваш маршрут** — карта с линией маршрута → `GET /route?from_id=X&to_id=Y`
6. **"Отлично! Ты нашёл..."** — финальный экран, кнопки "Найти другое место" / "В меню"
7. *(опционально, если успеваете)* **Сценарий "Первый день в ММУ"** — пошаговые реплики персонажа → `GET /scenarios`, `GET /scenarios/{id}`

Переходы между экранами (роутинг), сохранение состояния между шагами
(выбранная категория, откуда/куда идём) — спроектировать самостоятельно,
исходя из выбранного стека. Готового решения нет.

## API — полное описание

### `GET /categories`
```json
[{ "id": 1, "slug": "deanery", "title": "Деканат", "icon": "🏢" }]
```

### `GET /locations`
Query-параметры (можно комбинировать, все необязательные):
- `category` — slug категории, напр. `library`
- `floor` — номер этажа
- `entry_points_only` — `true` → только точки, которые можно выбрать как "я сейчас здесь"

```json
[{
  "id": 16, "name": "Кафедра", "room_number": "305", "floor": 3,
  "x": 30.0, "y": 40.0, "is_entry_point": 0, "category_id": 6
}]
```
`x`/`y` — условные координаты 0–100 (как проценты) для отрисовки на карте.
Пока тестовые значения, формат не изменится, когда появятся реальные.

### `GET /locations/{id}`
Детали одной локации. 404, если не найдена.

### `GET /route?from_id={id}&to_id={id}`
```json
{
  "from_location": { "...": "..." },
  "to_location": { "...": "..." },
  "path": [
    { "location": { "...": "..." }, "distance_from_start": 0.0 },
    { "location": { "...": "..." }, "distance_from_start": 42.0 }
  ],
  "total_distance": 42.0,
  "estimated_time_minutes": 2.0
}
```
`path` — упорядоченные точки маршрута, по ним рисуется линия на карте.
404, если одна из точек не существует или маршрут не найден.

### `GET /scenarios`
```json
[{ "id": 1, "slug": "first_day", "title": "Первый день в ММУ", "description": "...", "steps": [ ... ] }]
```

### `GET /scenarios/{id}`
```json
{
  "id": 1, "slug": "first_day", "title": "Первый день в ММУ",
  "steps": [{
    "id": 1, "order": 1,
    "message": "Привет! Я Novi 👋 Давай для начала найдём деканат...",
    "target_location": { "id": 12, "name": "Деканат", "room_number": "201", "...": "..." }
  }]
}
```

Все ответы — JSON. Ошибки в формате `{ "detail": "текст ошибки" }`.
